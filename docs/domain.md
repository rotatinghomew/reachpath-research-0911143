# 随机返券活动中曝光中介路径资料约定

一位用户仅有一次分组，分析总体以所有随机用户为基础。处理后库存和商家响应在曝光前记录，可能受到返券活动影响。曝光与成交窗口无重叠，时间戳均有时区；缺失曝光不可编码为零。随机资格本身可支持意向处理总效应，不自动赋予曝光或领券随机性。现有证据没有声称所有中介混杂均被观测。

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。

## 路径分析口径

### 时序与 DAG

每个用户内部事件截点严格有序：`baseline.available_at` < `assignment.assigned_at` < `response.occurred_at` < 曝光窗口 < 成交窗口（曝光结束与成交开始允许在同一时刻相接，两窗口不重叠）。路径分析在合表时逐人复核该次序并把违规用户数写入报告。

因果图的边为 X→Z（分层来源）、X→R/M/Y、Z→R/M/Y/C、R→M/Y、M→Y。库存与商家响应 R 在分组之后、曝光之前记录，既受活动影响又同时混杂 M→Y，是处理后混杂。实际领券 C 是处理后行为，只做描述，不进入识别用结构边。

### 估计量与识别状态

| 估计量 | 状态 | 依据与额外假设 |
| --- | --- | --- |
| ITT 总效应（Z→Y） | 已识别 | 仅依赖随机分组，Neyman 标准误，无模型假设 |
| Z→M 曝光的 ITT | 已识别（完整案例） | 随机化；缺失曝光不参与、不补零，缺失机制单独报告 |
| 干预型直接/间接效应 IDE/IIE | 依赖额外假设 | 允许处理后混杂 R 的 g-公式；需一致性、无干扰、R 被完整观测、参数模型设定正确、M 缺失为 MAR、正定性 |
| 自然直接/间接效应 NDE/NIE | 现有数据不可非参数识别 | 跨世界中介分布无观测对应；仅提供 rho 敏感性思想实验（不含 R 的顺序可忽略性设定） |
| 实际领券的因果效应 / CACE | 现有数据不可识别 | Z 对 C 是有效工具但排他性约束结构上不成立；处理组内领券对比标注为观察性差异 |

干预型目标写成 `E[Y(z, G_{z'})]`：把中介干预分布 `G_{z'}` 设为 arm=z' 组观测到的 (R,M) 经验联合分布（随机中介干预），再用 arm=z 的结果模型 `q(Y|Z=z,R,M,X)` 求期望。经验分布保留 R 与 M 的相关结构，且不需要对几乎不可由基线预测的 X→R 关系做参数假设（本数据 R 模型 R²≈0.01，参数外推会放大偏差）。两条分解恒等：`TE = IDE(z=0) + IIE(z=1) = IDE(z=1) + IIE(z=0)`，报告给出残差检验。该目标与时序相容，因为它不要求同一用户两个世界中介值的联合分布。

### 估计与防护

- 基线特征（`prior_orders`、`stratum`、`region`）只用于调整；五折分层交叉拟合，中心化常数与模型系数仅在训练折学习，留出折产生反事实预测，避免同折拟合与估计。
- 结果模型为按 arm 分别拟合的线性概率模型（含 R、M），不假设跨组系数不变；交叉验证显示其在观测协变量上校准良好（留出折预测均值与实际成交率差距小于 0.002）。
- `G_{z'}` 从训练折同臂完整案例的经验 (stock, merchant_response, impressions) 联合样本有放回 Monte Carlo 抽样；缺失 M 的单元不进入该池。自然臂 `E[Y(z,G_z)]` 的预测均值与观测成交率一致、g-公式 TE 与随机化 ITT 一致，作为内部校准检查随报告数值可复核。
- 区间为按 (arm, stratum) 分层重抽的自助百分位区间；随机种子、折数、Monte Carlo 抽样数与自助次数全部写入报告，同一参数下结果确定可复算。
- 朴素 pooled 回归（直接控制 R、M 后读取 Z 系数）仅作为反例输出并附警告，不参与路径分解。
- 报告的 `identification` 段逐项标注“已识别 / 依赖额外假设 / 不可识别”；宁可给出有限结论，也不把假设性结果包装成显著路径。
