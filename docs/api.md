# 资料服务接口

服务只在本机提供 JSON，响应编码为 UTF-8。查询接口不修改资料。

| 方法和路径 | 当前行为 |
| --- | --- |
| `GET /health` | 数据指纹和存活状态 |
| `GET /tables` | 表、字段类型和记录数 |
| `GET /tables/{name}?offset=0&limit=50` | 原始资料分页；偏移非负，每页一至五百行 |
| `GET /view` | 当前领域经营资料摘要 |
| `GET /profiles` | 数值字段的观察数、缺失数、中位数及绝对中位差 |
| `POST /cases` | 保存研究备注和当前完整资料副本；返回新记录 |
| `GET /cases` | 研究记录索引 |
| `GET /cases/{id}` | 校验完整性并回读记录 |
| `GET /paths` | 路径分析报告（按参数缓存，见下） |
| `POST /paths` | 把当前参数下的完整路径报告保存为不可变分析记录 |
| `GET /paths/records` | 分析记录索引 |
| `GET /paths/records/{id}` | 校验完整性并回读分析记录 |

创建研究备注的字段为 `label`、`options` 和 `notes`，分别是名称、参数对象与说明文字。名称一至一百二十字，后两项可省略。不接受其他字段，不允许覆盖旧记录。记录 ID 由服务生成。资料指纹由原始数据和结构共同形成，不表示计算结果的统计可信度。

路径分析参数通过查询串提供：`seed`（随机种子，默认 20261115）、`boot_reps`（分层自助次数，默认 200，上限 1000）、`folds`（交叉拟合折数，默认 5，上限 20）、`mc_draws`（g-公式 Monte Carlo 抽样数，默认 8）、`no_sensitivity`（出现即跳过 rho 敏感性）。`POST /paths` 额外接受请求体字段 `label`（可省略，默认“路径分析记录”）及与查询串同名的参数；除 `label` 外的未知字段返回 400，参数越界返回 400。报告本身不写盘，只有 `POST /paths` 产生带 SHA-256 校验的不可变记录（写入状态目录下的 `analyses/`）。

`GET /paths` 的报告保留随机分组口径：意向处理总效应只依赖随机化并单独报告；干预型直接/间接效应标注全部额外假设；自然效应与领券因果效应标注为现有数据不可识别。报告同时回传 DAG、每个用户的事件截点核对结果、共同支持越界统计和缺失曝光处理方式，缺失曝光从不补零。

源表未找到或记录 ID 无效返回 404；字段或分页无效返回 400。默认监听 127.0.0.1:8080。服务当前提供资料浏览、数值探索和研究备注，不将保存备注视为已经完成经营分析。
